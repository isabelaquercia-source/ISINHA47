# ISINHA47

## Queen UI Lab

Lab interativo para testar UIs: hub, torre de projeto, estudo, jogo, foco e veredito.

Abra a pasta `ui-lab/`:

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory ui-lab
```

Depois acesse `http://127.0.0.1:8765`.

## Câmera Distante Mobile

Treino de violão de "Losing My Religion" (R.E.M.) com o braço visto de longe, pensado para celular em pé. É um arquivo único: abra `camera-distante-mobile/index.html` no navegador, ou sirva a pasta:

```bash
python3 -m http.server 8766 --bind 127.0.0.1 --directory camera-distante-mobile
```

Depois acesse `http://127.0.0.1:8766`. Precisa de internet para carregar o Tailwind e a fonte.
