# ISINHA47

## Queen UI Lab

Lab interativo para testar UIs: hub, torre de projeto, estudo, jogo, foco e veredito.

Abra a pasta `ui-lab/`:

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory ui-lab
```

Depois acesse `http://127.0.0.1:8765`.
